3dsante

A publishing tool for an independent 3D animation creator.

3dsante is a personal content publishing tool operated by an independent 3D artist who produces short-form 3D animation and motion graphics. The creator already publishes this work on Facebook and YouTube, and uses 3dsante to publish the same work to their own TikTok account.

What the tool does

3dsante takes a finished video file that the creator has rendered, together with the caption and privacy setting the creator chooses, and uploads it to the creator's own TikTok account through the TikTok Content Posting API. It replaces the manual step of transferring each render to a phone and uploading it by hand.

How TikTok is used

  • The creator signs in with their own TikTok account using TikTok Login Kit.
  • 3dsante reads the account's basic profile information so the creator can confirm which account they are about to publish to.
  • 3dsante reads the account's posting limits and settings so the upload respects them.
  • 3dsante uploads the selected video to that account with the caption and privacy level the creator sets in the tool.

3dsante only ever publishes content the operator created themselves, only to the operator's own account, and only when the operator explicitly starts an upload. It does not post on behalf of other people, does not browse or collect other users' content, and does not run any automated engagement.
